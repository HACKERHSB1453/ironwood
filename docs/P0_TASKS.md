# P0 wave-2 task list

Skeleton (wave 1) is done: all interfaces in `src/<module>/*.hpp` compile, link and are covered by NotImplemented
stub tests. Wave 2 replaces stubs. Tasks are **file-disjoint**: each agent edits only its own files (listed), and
may add tests in its own `tests/test_<module>.cpp`. Interface headers are the contract: if a header must change,
stop and ask the supervisor (do not edit another task's files). Build/verify with
`cmake --build --preset debug && ctest --preset debug` (zero warnings, `-Werror`), plus `debug-clang` before finishing.
Every new file needs `// SPDX-License-Identifier: GPL-3.0-or-later`. Clean-room rule applies.

Dependency order: T1 first (T3, T4, T5 consume real shapes); T2, T6, T7 are independent; T8 last.

## T1 - Kernel implementation + STEP/STL import/export  (sonnet)
* Owns: `src/kernel/*.cpp`, `src/kernel/internal/*`, `src/kernel/THREAD_SAFETY.md`, `tests/test_kernel.cpp`
  (may add `tests/data/` fixtures).
* Implements: `Shape` (sub-shape ordering via `TopExp::MapShapes`-style unique walk, `boundingBox`, `isSame`),
  `makeBox/makeCylinder/extrudeProfile/fuse/cut/common`, `ShapeHistory` extraction (BOP history ->
  generated/modified/deleted/unchanged by index), `massProperties`, `importStep` (XDE: names, colours, assembly tree,
  units->mm), `importStl`, `exportStep`, `exportStl`.
* Acceptance: box/cylinder volumes exact; extrude of a rectangle gives 6 faces, 12 edges, 8 vertices and history maps
  each profile edge to one side face; cut/fuse volume checks; sub-shape counts and order identical across 100 repeated
  builds; STEP round trip keeps node count/names/colours/volume (fixtures generated by the test itself via
  `exportStep`); STL round trip area within 1%; error paths (missing file -> IoError, garbage -> ParseError).
  Update the THREAD_SAFETY.md rows touched (still UNVERIFIED unless a stress test is added).

## T2 - JobSystem (TBB) + LatestWins hardening  (haiku)
* Owns: `src/core/job.hpp`, `src/core/job.cpp`, `tests/test_core.cpp` (job tests only; do not touch other core tests).
* Implements: real priority handling (High before Normal before Low, e.g. three queues drained by arena workers),
  `waitAll`, destruction safety, exception safety, no TBB in headers.
* Acceptance: 10k-job stress; priority ordering test with a single worker; cancel-before-start never runs the body;
  LatestWins with 1000 rapid submits ends with exactly the newest result and all older handles Cancelled or completed;
  TSAN-clean (`-DIRONWOOD_SANITIZE=thread` configure).

## T3 - Tessellation  (sonnet; needs T1)
* Owns: `src/tess/*`, `tests/test_tess.cpp`.
* Implements: `tessellate` using `BRepMesh_IncrementalMesh` (parallel on a **copy**/private triangulation; the input
  Shape must stay untouched), face ranges by B-rep face index, edge polylines by edge index, normals, bounds, honour
  `CancelToken` (check between stages), `IW_ZONE` markers.
* Acceptance: box -> 12 triangles, 6 non-empty face ranges, 12 edge polylines; sphere/cylinder normals unit length;
  deflection monotonic (tighter -> more triangles); crack-free (watertight check via shared-edge vertex matching);
  bit-identical output over 50 runs; cancelled token -> `Cancelled`; input shape unchanged afterwards.

## T4 - Naming v0 + history -> NamingMap  (sonnet, strongest-available model preferred; needs T1 history)
* Owns: `src/naming/*.cpp`, `tests/test_naming.cpp`.
* Implements: `ElementName::toString/parse` (grammar in header, round-trip tested), `deriveNamingMap` per the policy
  in `naming_map.hpp`, `resolve` per the semantics in `resolve.hpp` (Exact / HistoryDerived / Ambiguous / NotFound;
  geometric fallback is out of scope for v0 - return NotFound).
* Acceptance: parse(toString(x)) == x for 1000 random names (including nested sources); extrude of rectangle gives 6
  distinct names; fuse of two boxes: surviving faces keep names, split faces get `.split` names with distinct ordinals;
  deleting a source element yields NotFound; ambiguity never silently picks; unit tests only use hand-built
  `ShapeHistory` until T1 lands, then add integration tests.

## T5 - Recompute Evaluator + extrude-only proof feature  (sonnet; needs T1, T4)
* Owns: `src/recompute/evaluator.cpp`, new `src/recompute/extrude_feature.{hpp,cpp}` (add to `src/recompute/CMakeLists.txt`),
  `tests/test_recompute.cpp`. (Does not edit `feature.hpp`/`timeline.*`.)
* Implements: `Evaluator::evaluate` with prefix-reuse cache keyed by the stamp chain (ARCH section 4), failure/skip semantics
  documented in `evaluator.hpp`, stamping of produced shapes, suppression and rollback marker; an `ExtrudeFeature`
  (rectangular/profile wire + vector parameters, registered under kind `"extrude"`) producing bodies + NamingMap.
* Acceptance: 3-feature timeline evaluates; editing feature 3 reuses 1-2 (`reusedCount == 2`); moving the rollback
  marker back and forth is all cache hits; suppress/unsuppress correct; failing feature -> Failed status, later ones
  evaluated against previous state; cancelled evaluation keeps a consistent cache; repeated evaluation yields identical
  stamps and sub-shape counts.

## T6 - Viewport, camera, navigation, ViewCube, picking  (sonnet)
* Owns: `src/render/*` (not `vulkan_support.*` semantics, only extend), `src/ui/*`, `apps/ironwood/*`, `tests/test_render.cpp`, `tests/test_ui.cpp`.
* Implements: Camera maths (orbit/pan/zoom-to-cursor/fit/matrices, ortho+persp), mouse mapping driven by
  `navMappingFor`, QRhi scene rendering (shaded + edge lines; shaders via `qt_add_shaders`), ViewCube overlay,
  async GPU-ID-buffer picking with ring-buffer readback, validation layer via `createVulkanInstance`.
* Acceptance: camera unit tests (fit contains bounds; zoom-to-cursor keeps the point under the cursor fixed within 1e-6;
  pitch clamp); offscreen widget test constructs `MainWindow` under `QT_QPA_PLATFORM=offscreen`; manual checklist for
  the supervisor with a display (orbit/pan/zoom feel, ViewCube clicks, pick highlights). Do not launch the GUI in CI.

## T7 - Native document I/O format  (haiku)
* Owns: `src/io/document_io.cpp`, `src/io/FORMAT.md`, `tests/test_io.cpp`.
* Implements: `saveDocument/loadDocument` per FORMAT.md v0 (manifest.json; small hand-written or header-only JSON
  writer/parser kept private to io, no new third-party dependency without supervisor approval), temp-dir + rename,
  `FeatureRegistry` use, version check.
* Acceptance: save/load round trip of a timeline of test features (defined in the test) preserves ids, order, suppressed
  set, rollback marker, `nextId`, unit; unknown kind -> NotFound; version 99 -> ParseError; truncated/corrupt manifest ->
  ParseError; existing target directory is not clobbered on failure.

## T8 - CLI, bench harness, determinism test  (haiku; after T1, T3, T5)
* Owns: `apps/ironwood-cli/*`, new `bench/` (own CMakeLists, added via a one-line `add_subdirectory(bench)` in the
  top-level `CMakeLists.txt` - the only shared-file edit allowed), new `tests/test_determinism.cpp` (+ line in `tests/CMakeLists.txt`).
* Implements: `ironwood-cli import <step> --stats` (nodes, solids, faces, edges, triangles, cold import time, peak RSS),
  `bench` executable (import, tessellate, evaluate timings; JSON output for future baselines), determinism test: N=20 repeated
  box/extrude/boolean/tessellate pipelines -> identical sub-shape counts, naming strings and mesh bytes.
* Acceptance: `ironwood-cli import fixture.step --stats` prints real numbers; bench runs in < 30 s; determinism test
  green in debug and release presets; failures print the first differing quantity.
